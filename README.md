# Random Color Changer

A simple interactive project built with HTML, CSS, and JavaScript.

## Features

- Move the heading element before or after the div element.
- Change the div background color randomly by clicking the button.
- Prevent the same color from appearing twice in a row.
- Use JavaScript DOM manipulation and event listeners.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## What I Learned

- Selecting DOM elements.
- Using `addEventListener()`.
- Working with arrays and random numbers.
- Using `while` loops and conditional logic.
- Manipulating DOM elements with `before()` and `after()`.
- Changing CSS styles using JavaScript.
- Managing state with variables.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
